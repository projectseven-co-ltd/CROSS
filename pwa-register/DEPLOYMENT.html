🚀 CROSS PWA Registration - Deployment Guide

Quick Start Options

Option 1: Local Testing (Easiest)

Perfect for development and testing:

cd pwa-register
python -m http.server 8000

Then visit: http://localhost:8000

✓ Works offline | ✓ No deployment needed

Option 2: Vercel (Recommended - 1 minute setup)

Free, fast, and automatically updates from git:

  1. Sign up at vercel.com
  2. Connect your GitHub repo
  3. Click "Deploy"

✓ Free | ✓ Auto-deploys | ✓ Global CDN

Option 3: Netlify (2 minute setup)

  1. Go to netlify.com
  2. Drag & drop the pwa-register folder, or connect GitHub
  3. Done!

✓ Free | ✓ Drag & drop deploy | ✓ HTTPS included

Option 4: GitHub Pages

  1. Push to GitHub in folder /docs instead of /pwa-register
  2. Go to Settings → Pages → Source: Deploy from branch → /docs folder
  3. Automatically published at https://yourusername.github.io/CROSS

✓ Free | ✓ Part of your repo | ✓ HTTPS

Option 5: Azure Static Web Apps

  1. Connect your GitHub repo in Azure Portal
  2. Point to pwa-register folder
  3. Auto-deploys on push

✓ Free tier included | ✓ Azure integration | ✓ CI/CD included

Option 6: Traditional Hosting (Bluehost, GoDaddy, etc)

  1. Upload pwa-register folder contents via FTP/SFTP
  2. Or use control panel file manager

Use if you already have web hosting

Configuration Before Deployment

⚠️ Important: Update these values in app.js BEFORE deploying: 
// In pwa-register/app.js, lines 6-13:

const CONFIG = {
  NOCODB_URL: 'https://noco.app.p7n.net',  // ← Your NocoDB instance
  API_TOKEN: 'fDhJb1s9aK8yQsj99iSt6DOe9o518yGAwAdwezn1',  // ← Your token
  
  USERS_TABLE: 'mtsl8eo5bfxhg8h',      // ← Update with YOUR table IDs
  CROSSES_TABLE: 'mdk4garchpkpvsd',
  PRAYERS_TABLE: 'mt7iucs253e26u0',
};

How to find your NocoDB table IDs:

  1. Open NocoDB and go to your base
  2. Click on a table (e.g., "users")
  3. Look at the URL: noco.app.p7n.net?base=BASE_ID&nc=TABLE_ID
  4. Copy the TABLE_ID and update your CONFIG

Mobile Installation

iPhone/iPad (Safari)

  1. Open the PWA in Safari
  2. Tap the Share button
  3. Tap "Add to Home Screen"
  4. Done! App appears on home screen

Android (Chrome)

  1. Open the PWA in Chrome
  2. Tap menu (⋮) → "Install app"
  3. Or look for "Install" button that appears automatically

Desktop (Windows/Mac)

  1. Open in Chrome/Edge
  2. Click install icon in address bar
  3. App opens in a window (like a native app)

Troubleshooting

Problem: "API Token not working"

  • Check token is copied exactly (no extra spaces)
  • Verify NocoDB is accessible from your deployment domain
  • Check browser DevTools → Network tab for actual error

Problem: "CORS error"

  • Add your PWA URL to NocoDB's allowed origins
  • Or set up a backend proxy

Problem: "Users table not found"

  • Verify table ID is correct in CONFIG
  • Make sure table exists in NocoDB
  • Check API token has access to the table
